# 최종 평가 동결

아래 통과는 저장된 기준선 산출물의 검증이다. 후속 [선택 실행 실험](answer_coverage_KO.md)의 기준선은 기존 holdout에서 9/10을 거절했다. 과거 10/10을 현재 보장으로 해석하지 않는다. 후보는 기본 API에 적용하지 않았고 Docker도 재측정하지 않았다. 실험 결과는 매니페스트의 별도 항목으로 보존한다.

[English](final_evaluation.md) | [한국어](final_evaluation_KO.md)

## 동결 범위

최종 포트폴리오 평가는 평가 입력, 실행 설정, 모델 리비전, 측정 산출물, 핵심 구현 파일과 Docker 패키징을 SHA-256 해시로 연결한다. 현재 확률적 평가 경로의 시드는 378로 고정한다.

추가한 논문 20편은 정확도 평가 자료로 바꾸지 않는다. 정확도 주장은 기존 논문 10편의 검증 질문 40개로 제한한다. 추가 논문은 파싱과 실행 강건성 근거로만 사용한다.

| 실행 역할 | 모델 | 리비전 |
|---|---|---|
| 다국어 임베딩 | `intfloat/multilingual-e5-small` | `614241f622f53c4eeff9890bdc4f31cfecc418b3` |

검색 모델 리비전은 호스트 캐시와 성공한 Docker 벤치마크의 캐시에서 각각 확인했다. 실행 로더는 이제 Sentence Transformers에 정확한 리비전을 전달한다. 임베딩 캐시 식별자에도 리비전을 포함하므로 체크포인트가 바뀌었을 때 과거 벡터를 조용히 재사용하지 않는다.

NLLB는 기록된 CC-BY-NC-4.0 조건에 따라 로컬 비상업 포트폴리오 범위에서만 사용한다. Qwen은 과거 회귀 비교용으로만 남기며 현재 브라우저 답변 경로에서는 사용하지 않는다.

## MRR 수치 정정

과거 28일차 산출물에는 MRR 0.6317이 기록돼 있다. 현재 코드, CPU 검색 장치, 정확한 모델 리비전으로 다시 실행한 결과는 MRR 0.5838이다. Recall@5와 Recall@10은 모두 1.000이고 Top-5에서 누락된 Gold 페이지는 없다.

과거 페이지 순위는 일부 질문에서 이후에 저장된 답변 근거 및 현재 파이프라인과 일치하지 않는다. 당시 임베딩 캐시는 모델 이름만 기록하고 리비전을 저장하지 않았으므로 과거 실행 상태를 정확히 복원할 수 없다. 따라서 0.6317은 과거 결과로 표시해 보존하고 현재 대표 지표는 0.5838로 정정한다. 오래된 수치를 현재 성능처럼 제시하지 않기 위한 조치다.

## 최종 수용 기준

동결 상태는 다섯 평가 그룹을 모두 통과한다.

- 검색: Recall@5와 Recall@10은 1.000, MRR은 0.58 이상이며 Top-5에서 누락된 검증 Gold 페이지가 없다.
- 코퍼스: 추가 논문 20편이 모두 실행 스모크 테스트를 통과한다.
- 답변 거절: 답변 가능 질문 유지율은 0.95, 근거 없음 홀드아웃 거절률은 1.00이며 대체 응답을 허용하지 않는다.
- 답변 품질: 통과 또는 부분 통과율은 0.85, 인용 실패는 0건, 잘못된 거절은 최대 2건이다.
- 컨테이너: 질문 10개 모두 요청 언어와 인용 계약을 지키며 오프라인 재시작과 정리를 통과한다.

## 무결성과 변경 절차

`final_evaluation.json`은 동결 목록의 모든 출처에 대한 SHA-256과 전체 출처 묶음 해시를 저장한다. `final_performance.csv`도 별도 해시로 연결한다. 검증기는 두 파일을 메모리에서 다시 구성하고 저장 파일과 정확히 같은지 확인한다.

동결된 입력, 설정, 핵심 실행 파일, 평가 산출물, 의존성 파일, Dockerfile 또는 Compose 파일을 바꾸면 동결 산출물을 다시 만들고 전체 검증을 실행한 뒤 변경된 주장을 검토해야 한다.

```bash
python -B scripts/evaluate_frozen_retrieval.py
python -B scripts/build_evaluation_freeze.py
python -B scripts/validate_evaluation_freeze.py
python -B scripts/verify_project.py
```

## 알려진 한계

- 논문 30편 중 10편만 수동 검증 질문과 Gold 근거가 있다.
- 답변 품질 판정은 독립적인 사람 평가가 아닌 어시스턴트 주도 검토다.
- 고정 답변 20문항은 서로 다른 의미 기준으로 13개다.
- 컨테이너 검토는 논문 3편의 한영 질문 의미 5개다.
- 한국어 답변은 영어보다 느리고 표현이 덜 자연스럽거나 세부 내용이 빠질 수 있다.
- 컨테이너 검토의 정확한 Gold 페이지 일치는 4/10이지만 반환된 근거 문장은 모두 답변을 지지한다.
- 공개 배포, 계정, OCR, 그림 해석, 수식 해석과 다중 논문 비교는 포트폴리오 MVP 범위 밖이다.
