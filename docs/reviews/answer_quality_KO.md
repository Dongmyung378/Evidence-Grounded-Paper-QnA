# 답변 품질 검토

## 적용한 답변 경로

브라우저 실행은 다음과 같은 근거 우선 답변 경로를 사용한다.

1. 기존 운영 검색기가 근거 청크 5개를 반환한다.
2. 다국어 Cross-Encoder가 청크 안의 완전한 문장을 다시 정렬한다.
3. 참고문헌, 잘린 추출 문장, 표 비중이 높은 텍스트, 수식은 제외한다.
4. 영어 질문은 선택 문장 최대 3개를 이용해 추출형 답변을 만든다.
5. 한국어 질문은 선택한 영어 문장 최대 2개만 고정 리비전의 NLLB 모델로 번역한다.
6. 근거 ID는 애플리케이션이 직접 조립하고, 근거에 없는 숫자, 수식, 미번역 CJK 문자, 검증 지시 노출은 거절한다.

작은 생성 모델 하나에 내용 선택, 번역, 과학적 요약, JSON 형식, 인용 선택을 동시에 맡기던 구조를 분리했다. 모델이 자유롭게 인용 ID를 만들 수 없으므로 답변과 표시 근거의 연결도 결정적이다.

## 고정 20문항 비교

기존 균형 검토와 정확히 같은 저장 검색 근거를 사용했다. 답변을 만들 때 Gold 답변은 읽지 않았고, 출력 파일을 저장한 뒤에만 Gold를 열어 의미를 비교했다.

| 지표 | 기존 0.5B 경로 | 근거 우선 경로 | 변화 |
|---|---:|---:|---:|
| 통과 | 1 | 3 | +2 |
| 부분 통과 | 4 | 14 | +10 |
| 실패 | 15 | 3 | -12 |
| 엄격 통과율 | 0.050 | 0.150 | +0.100 |
| 통과 또는 부분 통과율 | 0.250 | 0.850 | +0.600 |
| 잘못된 거절 | 7 | 2 | -5 |
| 인용 지지 | 통과 9 | 통과 18 | +9 |
| 고정 근거 답변 시간 | 118.863초 | 12.480초 | -106.383초 |

시간 비교는 두 실행 모두 모델 로딩을 제외하고 저장된 검색 근거에서 답변 단계만 측정했다. 최초 실행 지연이나 PDF 업로드부터 답변까지의 전체 API 시간은 아니다.

## 적용 결정

검토된 답변 유용성이 분명히 좋아졌고, 모든 반환 주장을 선택 원문과 연결하며, 20문항 실행에서 검증 대체 거절이 0건이고, 답변 단계 시간도 줄었으므로 근거 우선 경로를 적용했다. 기존 Qwen 0.5B JSON 경로와 결과는 과거 기준선으로 유지한다.

운영 수준 품질을 의미하지는 않는다. 독립적인 사람 검토가 아닌 어시스턴트 주도 검토이며, 한영 질문 쌍을 제외하면 서로 다른 질문 의미는 13개다. 페이지 1 질문 2개는 아직 관련도 기준에서 잘못 거절되고, 일부 부분 통과는 고정 Top-5 근거에 Gold 세부 내용이 없는 데서 발생한다. NLLB 체크포인트는 CC-BY-NC-4.0이며 로컬 비상업 포트폴리오 데모에서만 사용한다.

## 재현 방법

```bash
python -B scripts/evaluate_grounded_generation.py
python -B scripts/build_grounded_generation_review.py
python -B scripts/validate_grounded_generation.py
```

저장 출력, 검토 라벨, 해시로 연결한 검토 결과는 `data/evaluation/grounded_generation_*.json*`에서 확인할 수 있다.
