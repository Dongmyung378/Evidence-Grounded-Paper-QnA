# Docker Compose 질의응답 벤치마크

[English](container_qna.md) | [한국어](container_qna_KO.md)

## 목적

이 벤치마크는 저장된 검색 결과가 아니라 포트폴리오 최종 제공 경로를 검증한다. 새로운 Docker Compose 프로젝트에서 백엔드와 UI 이미지를 빌드하고, HTTP로 논문 3편을 업로드 및 분석하고, 고정 질문 10개를 실행했다. 이후 네트워크 모델 로딩을 끈 상태로 컨테이너를 재시작하고 임시 실행 자원을 정리했다.

질문은 검증 벤치마크 논문 3편에서 고른 영어와 한국어 5쌍이다. 컨테이너 실행 중에는 Gold 답변과 근거를 읽지 않았다. 출력 생성이 끝난 뒤 의미 품질을 검토할 때만 Gold를 사용했다.

## 환경과 계약 검증

| 검증 항목 | 결과 |
|---|---:|
| Docker Engine | 28.5.2 |
| Docker Compose | 2.40.3-desktop.1 |
| 백엔드와 UI 상태 확인 | 통과 |
| UI HTTP 응답 | 200 |
| 논문 업로드 및 분석 | 3/3 |
| 질문 완료 | 10/10 |
| 질문과 답변 언어 일치 | 10/10 |
| 근거가 있는 답변의 추적 가능한 인용 | 10/10 |
| 검증 대체 응답 | 0 |
| 오프라인 캐시 재시작 | 통과 |
| 재시작 전후 결정적 응답 | 통과 |
| 임시 스택과 실행 자료 정리 | 통과 |

시드는 378을 사용했다. 컨테이너 내부의 임베딩, 재정렬, 번역 추론은 모두 CPU에서 실행했다.

세 논문 분석에서는 치명적이지 않은 파서 진단 91건이 기록됐다. 2단 편집 의심 31건, 긴 구간 분할 48건, 각주 형태 줄 유지 12건이다. 세 작업은 모두 완료됐고 텍스트 페이지 49/49와 추적 가능한 청크 195개를 생성했다. 이 수치는 추출 과정의 판단 기록이며 요청 실패 수가 아니다.

## 실행 시간

| 측정 항목 | 결과 |
|---|---:|
| 백엔드와 UI 빌드 | 111.999초 |
| 빈 모델 캐시에서 첫 논문 분석 | 106.471초 |
| 이후 논문 분석 평균 | 6.027초 |
| 영어 답변 API 평균 | 1.470초 |
| 영어 답변 API 최댓값 | 1.650초 |
| 한국어 답변 API 평균 | 11.950초 |
| 한국어 답변 API 최댓값 | 23.895초 |
| 한국어와 영어 API 평균 비율 | 8.13배 |
| 오프라인 재시작 스택 준비 | 12.650초 |
| 재시작 후 반복 한국어 답변 | API 11.912초, 전체 21.282초 |
| 영속 모델 캐시 | 6.46 GiB |

첫 분석 시간에는 빈 영속 캐시에 고정 모델을 내려받고 초기화하는 비용이 포함된다. 이후 두 논문은 각각 4.156초와 7.898초에 분석됐다. 재시작은 로컬 모델 파일만 사용했으며 처리된 논문 3편을 모두 유지했다. 같은 질문에 동일한 답변과 근거 페이지를 반환했고 캐시 파일 수와 크기도 변하지 않았다.

## 답변 의미 품질 검토

| 언어 | 통과 | 부분 통과 | 실패 | 통과 또는 부분 통과 |
|---|---:|---:|---:|---:|
| 영어 | 3 | 2 | 0 | 5/5 |
| 한국어 | 1 | 4 | 0 | 5/5 |
| 전체 | 4 | 6 | 0 | 10/10 |

수동 확인 결과 10개 답변의 반환 근거가 모두 해당 답변을 지지했다. 부분 통과의 주된 원인은 세부 내용 누락, 추출된 머리말 잡음, 어색한 한국어 번역이다. 이 검토는 어시스턴트가 수행했으며 독립적인 사람 평가가 아니다.

검증된 단일 Gold 페이지와 정확히 겹친 결과는 4/10이다. 따라서 이번 실시간 벤치마크에서는 Gold 페이지 번호의 정확한 일치를 인용 지지 기준으로 사용하지 않았다. 반환 근거는 추적 가능하고 의미상 답변을 지지하지만, 실시간 페이지 재현율을 주장하기 전에는 이 차이를 추가 점검해야 한다.

## 언어 지원 판단

한국어를 포트폴리오 MVP에서 유지한다. 한국어 질문 5개 모두 한국어 답변과 이를 지지하는 영어 원문 근거를 반환했고 의미 평가에서 완전 실패는 없었다. 다만 CPU 컨테이너의 한국어 생성은 평균 11.950초가 걸렸고, 4개 답변은 어색한 표현이나 세부 내용 누락으로 부분 통과였다. 이는 운영 수준의 속도나 번역 품질 보장이 아니라 명시된 포트폴리오 한계다.

이번 실행은 답할 수 있는 질문만 포함한다. 답변 거절 품질은 별도의 근거 없음 홀드아웃 질문 10개를 모두 거절한 결과로 검증한다.

## 재현 및 검증

영속 캐시가 비어 있으면 모델을 내려받으므로 전체 실행에 몇 분이 걸릴 수 있다.

```bash
python -B scripts/run_container_qna_benchmark.py
python -B scripts/build_container_qna_review.py
python -B scripts/validate_container_qna.py
```

벤치마크는 전용 Compose 프로젝트를 사용한다. 해당 프로젝트의 임시 실행 볼륨만 제거하고 반복 실행에 필요한 모델 캐시 볼륨은 보존한다.
