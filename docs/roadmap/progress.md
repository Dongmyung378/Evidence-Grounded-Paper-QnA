# 로드맵 진행 기록

이 문서는 최상단 README에서 분리한 일차별 작업 기록이다. 완료 여부는 사용자가 제공한 원 계획서의 작업과 완료 기준을 기준으로 판단한다.

## 1일차부터 6일차

- MVP 범위와 요구사항 확정
- arXiv 영어 논문 10편과 QASPER 구조 확인
- 검증된 한영 질문 40개와 Gold 답변 및 근거 구축
- 초기 파싱 파이프라인과 BM25 기준선 구현

## 7일차부터 14일차

- `intfloat/multilingual-e5-small` 기반 다국어 Dense 검색 구현
- BM25, Dense, Hybrid 검색 평가 기반 정리
- 페이지와 청크 추적성이 있는 수집 파이프라인 완성
- PDF 10/10, 188페이지, 906청크 파이프라인 검증 통과

## 15일차부터 20일차

- 공통 검색 인터페이스와 동일 평가 조건 정리
- BM25, Dense, Hybrid 기준선 비교
- 실패 질문 분석과 첫 검색 개선 실험 수행

## 21일차부터 24일차

- Hybrid 후보군과 Cross-Encoder 재정렬 구현
- 근거 선택 정책과 UI용 근거 객체 스키마 구현
- 페이지, 절, 청크 식별자, 원문을 포함한 근거 응답 검증

## 25일차부터 27일차

- 재정렬 학습 데이터와 미세조정 준비 경로 구축
- 구성 요소 제거 실험과 오류 수정
- 후보군 확대 실험은 이득이 없어 채택하지 않고 결과를 보존

## 28일차

- 논문을 10편에서 30편으로 확장
- 전체 563페이지와 2,463개 청크 처리
- 추가 20편은 파싱과 실행 강건성에 사용
- 정확도 평가는 기존 검증 10편과 40문항으로 동결
- 고정 검색 구성 Recall@5 1.000, MRR 0.6317 달성

## 29일차

- 근거 기반 답변 프롬프트와 JSON 출력 계약 구현
- `answer`, `evidence_ids`, `sufficiency`, `abstention_reason` 필드 검증
- 존재하지 않는 근거 식별자와 모순된 응답 상태 거부

## 30일차

- `Qwen/Qwen2.5-0.5B-Instruct` 로컬 생성 모델 연결
- 검색, 재정렬, 근거 선택, 생성, 출력 검증의 종단간 흐름 구현
- 영어 5개와 한국어 5개를 포함한 10편 실행 완료

## 31일차

- 근거 부족 질문을 위한 거절 정책 보정
- 홀드아웃 비정답 질문 10/10 거절
- 검증된 정답 가능 질문 40개 중 37개 유지

## 32일차

- 사실, 수치, 비교, 한계 질문을 각 5개씩 수동 검토
- 영어 10개, 한국어 10개, 기존 논문 10편 균형 구성
- 통과 1개, 부분 통과 4개, 실패 15개, 잘못된 거절 7개 기록
- 로드맵의 평가 작업은 완료했으나 답변 품질은 배포 수준이 아님을 확인

## 33일차

- `POST /upload`, `POST /analyze`, `GET /jobs/{job_id}` 구현
- PDF 형식과 크기 검증, 비동기 단일 작업자, SQLite 작업 상태 구현
- 페이지와 청크 추적성, 재시작 복구, 오류 정리 검증

## 34일차

- `GET /health`, `GET /papers/{paper_id}`, `POST /question` 구현
- 업로드 논문 전용 검색 인덱스와 근거 기반 답변 연결
- 실제 Uvicorn 서버와 curl 질문 요청 검증 통과

## 35일차

- UI 없이 실제 HTTP 환경에서 전체 API 흐름 검증
- PDF 업로드 -> 파싱 -> 청크 -> Dense 인덱스 -> 질문 -> 답변 성공
- 분석 전 질문 409, 미등록 논문 404 등 상태 계약 확인
- 인용 근거가 해당 런타임 청크의 페이지와 원문에 일치함을 검증
- 고정 평가 데이터가 변경되지 않았고 임시 런타임이 제거됨을 확인

## 현재 판단

원 계획의 35일차 완료 기준까지 충족했다. 검색 및 API 통합은 안정적으로 재현되지만, Day 32에서 확인된 생성 답변 품질 문제는 이후 개선 과제로 남아 있다. 다음 로드맵 작업은 간단한 웹 UI 구현이다.
