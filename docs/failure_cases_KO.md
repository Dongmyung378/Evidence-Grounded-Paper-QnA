# 실패 사례 분석

[English](failure_cases.md) | [한국어](failure_cases_KO.md)

동결된 포트폴리오 평가에서 대표적인 실패와 준실패 10건을 분석했습니다. 검색 순위, 근거 선택, 답변 거절 정책, 답변 완전성과 한국어 번역을 분리해 높은 검색 성능이 완전한 답변 품질로 오해되지 않도록 했습니다.

## 핵심 결과

- 고정 20문항 답변 검토에서 확인된 인용 hallucination은 없습니다. 인용 지지 실패는 0건입니다.
- 답변 가능한 질문 2개는 상위 재정렬 점수가 고정 임곗값 `-3.35`보다 낮아 잘못 거절됐습니다.
- 비근거 한국어 홀드아웃 질문 1개는 같은 임곗값을 통과했습니다. 이 평가에서는 답변 생성을 실행하지 않았으므로 확인된 hallucination이 아니라 hallucination 노출 위험입니다.
- Gold 페이지의 순위가 높아도 부분 답변이 발생했습니다. 남은 문제는 페이지 검색보다 페이지 내부 근거 선택이나 답변 조립의 불완전성인 경우가 많습니다.
- 한국어 실패에는 같은 근거 범위 문제와 느리고 어색할 수 있는 번역 문제가 함께 나타납니다.

`q-001`과 `q-042`는 한영 대응 문항이므로 10개 레코드는 서로 다른 질문 의미 8개를 나타냅니다.

## 상세 사례

### 1. q-001-en

**질문:** What is the main problem addressed in this paper?

**관찰:** 검증 페이지는 검색 1위지만 상위 재정렬 점수가 `-5.54`로 답변 거절 임곗값보다 낮습니다. 시스템은 근거 부족 응답을 반환합니다.

**원인과 영향:** 페이지 검색은 성공했지만 전역 점수 임곗값이 답변 가능한 근거를 무관하다고 판단합니다. 잘못된 답변 거절로 답변 가능 문항 유지율이 낮아집니다.

**개선안:** Sparse와 Dense 검색의 동의 정도, 선택 문장 범위와 질문 유형을 함께 사용하는 다중 신호 정책을 검토합니다. 임곗값만 낮추면 비근거 답변이 늘 수 있으므로 홀드아웃을 반드시 함께 평가해야 합니다.

### 2. q-001-ko

**질문:** 이 논문에서 다루는 주요 문제는 무엇인가?

**관찰:** 검증 페이지는 3위지만 상위 점수가 `-4.12`입니다. 답변 가능한 영어 질문의 한국어 대응 문항도 거절됩니다.

**원인과 영향:** 언어 간 점수 차이가 있어도 임곗값 오류가 해결되지 않습니다. 한영 대응 문항이 함께 실패하므로 답변 생성보다 거절 정책이 직접적인 원인입니다.

**개선안:** 하나의 안전 정책을 유지하면서 언어별 점수 보정이나 이중언어 의미 지지 신호를 평가합니다.

### 3. abs-test-006-ko

**질문:** 이 논문에서 목성의 위성 수는 몇 개라고 제시하는가?

**관찰:** `paper-016`과 무관한 질문이지만 상위 점수는 `-2.02`로 `-3.35`보다 높아 생성 전 정책에서 답변 가능으로 판정됩니다.

**원인과 영향:** 우연한 의미 중복만으로 단일 관련도 점수가 높아질 수 있습니다. 이 평가는 정책 판정에서 종료되므로 실제 비근거 답변이 생성되지는 않았지만 hallucination으로 이어질 수 있는 경로입니다.

**개선안:** 생성 전에 근거 함의 또는 답변 가능성 검사를 추가하고 적대적인 범위 밖 질문을 임곗값 평가에 포함합니다.

### 4. q-017-ko

**질문:** 이 논문은 표현 학습과 과정 추론을 어떻게 연결하는가?

**관찰:** Gold 페이지는 1위지만 반환 답변은 필요한 observation-to-inference hierarchy 대신 지구 관측 데이터와 하류 적응을 설명합니다.

**원인과 영향:** 페이지 검색은 성공했지만 선택 청크에 질문이 요구하는 구체적인 관계가 없습니다. 관련 근거를 사용하는 유창한 답변이지만 질문에 직접 답하지 못합니다.

**개선안:** 관계를 묻는 질문에 대해 문장을 다시 정렬하고, 답변 조립 전에 질문의 핵심 개념이 근거에 포함됐는지 확인합니다.

### 5. q-015-en

**질문:** What evidence shows that the proposed approach improves continual anomaly detection?

**관찰:** Gold 페이지는 1위입니다. 답변은 최고 수준 성능과 온라인 설정을 언급하지만 11개 작업 일정과 MVTecAD, VisA 데이터셋을 누락합니다.

**원인과 영향:** 선택 문맥이 결론은 담지만 정량적 평가 설정은 담지 못합니다. 근거는 있지만 불완전한 답변입니다.

**개선안:** 평가 근거를 묻는 질문에는 정량 결과와 데이터셋 또는 실험 설정을 위한 근거 슬롯을 각각 확보합니다.

### 6. q-042-en

**질문:** How is the Microlensify classifier evaluated on TESS light curves?

**관찰:** Gold 페이지는 5위입니다. 답변에 Sector 12와 Eleanor는 있지만 SPOC, QLP와 정제 후 후보 수가 없습니다.

**원인과 영향:** 관련 페이지가 Recall@5 경계에 있고 근거 5개 제한 안에서 여러 파이프라인의 전체 결과가 보존되지 않습니다.

**개선안:** 순위가 낮은 정량 페이지 주변의 근거를 확장하거나 여러 부분으로 구성된 평가 절차 질문에서 인접 청크를 결합합니다.

### 7. q-042-ko

**질문:** Microlensify 분류기는 TESS 광도 곡선에서 어떻게 평가되는가?

**관찰:** Gold 페이지는 마찬가지로 5위입니다. 한국어 답변은 Eleanor와 넓은 실험 설정을 유지하지만 SPOC, QLP와 정제 수치를 누락합니다.

**원인과 영향:** 번역은 선택된 영어 근거에 없는 사실을 복원할 수 없습니다. 한국어 답변 품질도 우선 근거 범위에 좌우된다는 사례입니다.

**개선안:** 번역 모델보다 근거 선택을 먼저 개선하고, 파이프라인 이름과 수치가 번역 후에도 보존되는지 검증합니다.

### 8. q-043-ko

**질문:** 다중 소스 distributionally robust graph learning을 평가하기 위해 어떤 실험이 사용되는가?

**관찰:** Gold 페이지는 1위입니다. 합성 실험과 다기관 fMRI 실험은 유지하지만 용어가 어색하고 ABIDE I, 7개 baseline과 평가 지표를 누락합니다.

**원인과 영향:** 관련 근거가 있어도 문장 압축과 번역 과정에서 고유명사와 비교 세부사항이 사라집니다.

**개선안:** 번역 중 모델, 데이터셋과 지표 이름을 보호하고 요청된 비교 차원을 모두 포함했는지 검사합니다.

### 9. q-041-ko

**질문:** GOAG의 성능은 어떻게 평가되는가?

**관찰:** Gold 페이지는 2위입니다. MultiDex와 100회 추론은 포함하지만 세 그리퍼의 이름, 효율성과 다양성을 누락합니다.

**원인과 영향:** 일반적인 평가 절차는 전달하지만 요청한 평가 차원을 모두 다루지 못해 부분 통과입니다.

**개선안:** 목록 형태 근거를 탐지하고 문장 선택과 답변 조립에서 병렬 항목을 유지합니다.

### 10. q-034-en

**질문:** What assumptions are required for the main result about logarithmic Voronoi cells?

**관찰:** Gold 페이지는 2위입니다. 일차원 대수적 설정과 비대수적 결과는 설명하지만 확률 단체와 두 가지 구체적 구성을 누락합니다.

**원인과 영향:** 질문이 요구한 가정보다 넓은 결론을 중심으로 답변합니다. 문장 자체는 근거가 있지만 질문에 완전히 답하지 못합니다.

**개선안:** 가정과 제한을 묻는 질문을 별도로 분류하고 조건, 정의역과 구성 제약을 포함한 문장을 우선 선택합니다.

## 포트폴리오 공개 이후 우선순위

1. 동결된 Top-5 검색 성능을 바꾸지 않으면서 검색 페이지 내부의 근거 범위를 개선합니다.
2. 단일 점수 답변 거절을 보정된 다중 신호 정책으로 교체하고 답변 가능성 평가 60건을 다시 측정합니다.
3. 근거 선택 문제를 해결한 뒤 한국어 번역에서 고유명사와 비교 목록을 보존합니다.

이 항목은 향후 작업 목록이며 측정되지 않은 성능 개선 주장이 아닙니다. 동결된 최종 지표는 변경하지 않습니다.
