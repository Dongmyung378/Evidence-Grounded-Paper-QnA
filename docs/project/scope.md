# 프로젝트 범위

## 목표

텍스트 추출이 가능한 영어 논문 PDF 한 편을 입력받아, 논문 원문에 근거한 한국어 또는 영어 답변과 인용 정보를 제공한다.

## 지원 범위

- 영어 학술 논문 PDF
- 한 번에 논문 한 편 업로드 및 처리
- 최대 파일 크기 20 MiB
- 한국어 또는 영어 질문
- 질문 언어와 같은 언어의 답변
- 제목, 초록, 본문, 절 제목 등 추출 가능한 텍스트
- 페이지, 절, 원문 근거, 청크 식별자 표시

## 핵심 기능

1. PDF 업로드
2. 논문 개요 확인
3. 다국어 질문과 답변
4. 원문 근거와 위치 표시
5. 근거 부족 시 답변 거절

## MVP 제외 범위

- 스캔 PDF와 OCR
- 이미지, 표, 그래프, 수식의 의미 해석
- 여러 논문의 동시 처리와 비교
- 영어 이외 언어로 작성된 논문
- 회원, 결제, 대규모 논문 검색
- Kubernetes, 마이크로서비스, 다중 LLM 라우팅

## 답변 원칙

- 선택된 논문 한 편의 추출 텍스트만 근거로 사용한다.
- 외부 지식을 사실 근거처럼 사용하지 않는다.
- 근거가 충분하지 않으면 질문 언어로 명확하게 답변을 거절한다.
- 답변에 사용한 원문 근거가 페이지와 청크로 역추적되어야 한다.
