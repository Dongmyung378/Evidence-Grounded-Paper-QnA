# 논문 30편의 이중 언어 평가

[English](README.md) | [한국어](README_KO.md)

기존 텍스트 코퍼스의 논문 30편 전체에서 최종 답변을 평가합니다. 의미 그룹 180개에 영어와 한국어를 대응시켜 출력 360개를 구성했습니다. 논문마다 근거가 있는 질문 4개, 근거가 없는 요청 1개, 원문과 모순되는 전제의 질문 1개가 있습니다. 번역 질문은 같은 분할에 유지하며 독립적인 과학 질문으로 두 번 세지 않습니다.

논문 001–010은 이미 검색 라벨과 구현 개선에 사용했으므로 개발용입니다. 논문 011–030은 문서 처리와 검색 실행 확인에 사용했으며, 프로젝트 기록에는 이 논문의 답변 채점 결과를 활용한 설정 조정이 없습니다. 이 이력은 운영자 기록이며 독립적으로 감사한 자료 오염 보장은 아닙니다. 모델의 사전학습 자료와 겹치는지도 확인하지 않았습니다.

## 고정 입력

- `manifest.json`은 논문 출처, 이용 조건, 원문 해시와 분할을 기록합니다.
- `questions.jsonl`은 대응 질문, 허용 출처 페이지와 필수 사실의 표기 대안을 기록합니다.
- `protocol.json`은 채택 기준과 제한된 개발 실험 범위를 기록합니다.
- `freeze.json`은 입력 파일의 정확한 바이트를 보호합니다.

실행 파이프라인에는 질문과 해당 논문의 ID만 전달합니다. 정답 위치, 답변 가능 여부와 사실 표기는 채점에만 사용합니다. `gold_pages`는 허용 가능한 근거 위치의 목록이며, 해당 페이지를 인용했다는 사실이 주장의 타당성을 입증하지는 않습니다.

## 측정 범위

사실 표기의 포함 여부는 어휘 수준의 관찰 지표입니다. 올바른 동의어를 놓치거나 잘못된 문장에 포함된 사실을 통과시킬 수 있습니다. 답변 유지, 거절 상태, 출력 형식과 인용 위치를 따로 집계하며 의미상 정확도와 독립적인 사람의 검토를 구분합니다. 라벨은 원문을 읽은 AI 보조 작성자가 구성했으며 독립적인 사람의 정답 판정이 아닙니다.

주 지표는 두 언어가 모두 조건을 만족해야 의미 그룹을 통과시킵니다. 언어별 결과와 개별 실패도 함께 제공합니다. 텍스트 입력 평가는 PDF 파싱을 거치지 않으며 시각적 표와 그림 또는 수학적 유도를 평가하지 않습니다.

## 재현

실제 추론에는 Python 3.12와 `requirements.txt` 및 고정된 모델 파일이 필요합니다. `--offline`은 모든 모델이 이미 캐시에 있을 때만 사용합니다.

```bash
python -B scripts/corpus_benchmark.py validate
python -B scripts/corpus_benchmark.py run --split dev --variant reproduction --offline --output outputs/reproduction-dev.json
python -B scripts/corpus_benchmark.py evaluate --predictions outputs/reproduction-dev.json --output outputs/reproduction-dev-report.json
```

실험 출력은 `outputs/`에만 기록하며 공개 근거를 덮어쓰지 않습니다. 결과를 공개한 평가 분할은 이후 회귀 검증에 사용하고, 새로운 일반화 성능은 별도로 보류한 논문으로 측정해야 합니다.

## 공개 비교 결과

[결과와 실패 분석](../../../docs/results_KO.md)은 개발 선택, 최종 논문 20편 비교, 알려진 스칼라 회귀 사례와 실행 순서의 이탈을 구분합니다. [저장된 출력과 보고서](results/)에는 버전별 전체 출력 360개와 명시적으로 나눈 개발 및 평가 자료가 있습니다. 선택 당시 개발 기준 구현과 정식 비교의 반복 기준 구현을 구분해 보존하며 동일한 채점기로 계산합니다.

`python -B scripts/validate_corpus_benchmark.py`로 추론 없이 공개 지표를 다시 계산할 수 있습니다. 답변을 다시 생성하려면 저장소 최상위 폴더에서 `scripts/replay_corpus_benchmark.py --variant baseline|final --split dev|holdout --offline --output outputs/replay.json`을 실행하며 각 선택지에서 값 하나를 지정합니다. 측정 당시 목록에 있는 파일만 복원하고 임베딩을 재생성합니다. 세 개발 안이 고정 기준을 통과하지 못해 최종 기본 설정의 실험 선택 기능은 비활성화했습니다. 원문 대응과 문장 내 스칼라 인식 수정은 유지합니다.
