# 전제 검증 모델의 타당성 실험

[English](README.md) | [한국어](README_KO.md)

이 모델은 채택하지 않았습니다. 잘못된 전제는 영어와 한국어 모두에서 10개 그룹 전체를 거절했지만, 올바른 전제를 두 언어에서 모두 받아들인 경우는 2/10개뿐이었습니다. 실행 전에 정한 기준은 올바른 전제 수용 9/10개 이상, 잘못된 전제 거절 8/10개 이상입니다. 정상 요청을 지나치게 거절하므로 부정 질문의 점수만으로 채택하지 않았습니다.

영어 전용 [nli-MiniLM2-L6-H768 모델](https://huggingface.co/cross-encoder/nli-MiniLM2-L6-H768)의 `b95119ce93d3e065de6214e38cd4a97b0f2f2c6d` 리비전을 사용했습니다. 해당 논문에서 BM25로 고른 12개 구절에 대해 함의 확률 0.8 이상을 수용했습니다. 한국어 주장은 기존 NLLB 가중치로 영어로 역번역했습니다. 모델의 영어 전용 특성과 역번역의 전문 용어 왜곡이 정상 전제의 과도한 거절에 영향을 미쳤습니다.

[실험 프로토콜](protocol.json)은 40개 언어 입력과 정상 전제 대조군, 판정 기준을 실행 전에 고정했습니다. [예측 결과](predictions.json)에는 확률, 선택한 원문과 번역이 남아 있고 [해시](freeze.json)로 보호합니다. 이미 공개된 개발 논문 10편을 대상으로 수행했으며, AI 보조 원문 검토를 사용했습니다. 독립적인 사람의 검증은 아닙니다. 전체 답변 평가와 분리한 실험이며 기본 서비스에는 적용하지 않았습니다.

추론 의존성을 설치한 뒤 `python -B scripts/experiment_premise_verifier.py --offline --output outputs/premise-verifier-replay.json`으로 재실행할 수 있습니다. 오프라인 실행에는 이 분류기의 지정 리비전도 Hugging Face 캐시에 있어야 합니다. 처음 다운로드할 때는 `--offline`을 생략합니다. 모델 가중치와 실행 환경의 절대 경로는 공개 파일에서 제외했습니다.
