# 데이터 디렉터리 안내

| 경로 | 내용 |
|---|---|
| `raw/papers/` | 로컬 원본 PDF, Git 제외 |
| `raw/qasper/` | 로컬 QASPER 원본, Git 제외 |
| `metadata/` | 논문 출처, 라이선스, 파일 메타데이터 |
| `processed/` | 페이지, 청크, 파이프라인 산출물 |
| `evaluation/` | 평가 입력, 지표, 모델 출력, 검증 보고서 |
| `runtime/` | 사용자가 업로드한 논문의 실행 중 산출물, Git 제외 |

원본 PDF와 사용자 업로드 파일은 공개 저장소에 포함하지 않는다. 평가용 JSON과 JSONL은 코드에서 읽는 기계 데이터이므로 키와 원문 언어를 임의로 번역하지 않는다.
