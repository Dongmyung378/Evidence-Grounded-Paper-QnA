# corpus30 측정 당시 구현

[English](README.md) | [한국어](README_KO.md)

`baseline/`은 기존 커밋의 소스 및 설정에 고정 평가 실행기를 더한 파일 75개를 보존합니다. `final/`은 세 전략 실험을 제외한 뒤 측정한 파일 80개를 보존합니다. `development-v3/`은 마지막에 제외한 전략입니다. 각 `snapshot.json`에 정확한 바이트의 해시가 있으므로 변경하면 측정 출력과 일치하지 않습니다.

외부 재현 명령은 선택한 스냅샷 목록의 파일만 복원합니다. 측정 후 복원 도구를 수정해 최신 저장소 파일이 과거 구현에 섞이지 않게 했으며, 측정한 추론 소스는 변경하지 않았습니다. 스냅샷 내부의 이전 복원 도구도 출처 기록으로 보존하지만 외부 복원 과정에서 실행하지 않습니다.

[평가와 결과](../../benchmarks/corpus30/README_KO.md)에 범위와 제외 이력을 설명합니다. 개인 기록, 원본 PDF, 모델 가중치와 임베딩 캐시는 포함하지 않습니다.
