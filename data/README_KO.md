# 데이터 디렉터리

[English](README.md) | [한국어](README_KO.md)

`quality_benchmark/`에는 이중 언어 검증 자료, 실논문 원문, 최종 출력과 범위를 제한한 모델 비교 실험이 있습니다. `baselines/`에는 과거 측정의 출처를 검증할 수 있도록 당시 구현 바이트를 보존합니다.

- `benchmarks/corpus30/`에는 논문 30편의 고정된 영어 및 한국어 평가와 현재 측정 결과를 보관합니다.
- `metadata/`에는 논문 30편의 출처와 라이선스 매니페스트가 있습니다.
- `processed/`에는 추출 페이지, 검색 청크와 수집 매니페스트가 있습니다.
- `evaluation/`에는 검증 문항, 검토 근거, 최종 지표와 출처 산출물이 있습니다.
- `raw/`와 `runtime/`은 로컬 전용이며 Git에서 제외합니다.

코퍼스 범위와 재배포 정책은 [데이터와 라이선스](../docs/data_KO.md)를 참고하세요.
